# Pickles — playtest checklist

Проверка оверлея засолки на локальном сервере (`localhost:1212`).

CVar: `pickles.enabled true`. Dev + Sandbox удобнее всего для спавна.

## Подсказки при старте ферментации

Альт-верб **«Начать ферментацию»** на idle-бочке. Ожидаемый popup:

| Сценарий | Ожидаемая подсказка (RU) |
|---|---|
| Бочка пустая (нет овощей) | Сначала положите продукты в бочку. |
| Овощи есть, жидкости нет | В бочке нет рассола. Налейте уксус, соль или сахар. |
| Только вода | Одна вода ничего не замаринует… |
| 1 огурец + уксус + сахар | Мало продуктов: для «…» нужно 3 шт., сейчас 1. |
| 3 огурца + уксус, **без** сахара | Для маринада с уксусом нужен сахар: около N ед. (сейчас 0). |
| 3 огурца + мало уксуса + сахар | Мало уксуса: нужно около N ед. (сейчас M). |
| 3 капусты + мало соли | Мало соли: нужно около N ед. (сейчас M). |
| Неподходящий продукт | «…» не подходит ни под один рецепт засолки. |
| Слишком холодно / жарко | Здесь слишком холодно… / Слишком жарко… |
| Всё ок | Вы герметизируете бочку и оставляете партию бродить. |

Спавн для быстрых проверок:
```
spawn PickleBarrelWood
spawn FoodCucumber
spawn FoodCondimentBottleVinegar
spawn ReagentContainerSugar
```

## Расы: еда из банки (Z) и руками

Открытая банка с маринованным/солёным огурцем. Сравнить **взять кусок рукой** vs **Z / Use in hand** на банке.

| Раса | Кусок в руке (есть) | Z на банке | Ожидание |
|---|---|---|---|
| Человек | Ест | Ест | Оба пути работают |
| Кобольд | Не ест овощи (cant-digest) | **Не** ест, popup cant-digest | Z не обходит диету |
| IPC (монитор) | Нет рта/желудка — не ест | **Не** ест | Z не кормит робота |
| Вокс | По правилам диеты вокса | То же, что руками | Пути совпадают |

Как проверить быстро:
1. Замариновать 3 огурца → открытой банкой забрать партию.
2. Сменить расу / заспавнить моба (`spawn MobKobolt`, `spawn MobIPC` / аналог на форке, `spawn MobVox`).
3. Выдать банку в руку → Z.
4. Достать кусок вербом/рукой → попытаться съесть отдельно.

## Регресс

- [ ] После успешного старта бочка уходит в Fermenting, examine показывает прогресс.
- [ ] Банка после сбора: рассол в банке, бочка пустая (tank 0).
- [ ] Спрайт банки: fill и овощи не вылезают за стекло; в мире банка меньше иконки UI.
- [ ] Пластиковой бочки нет (только деревянная).
