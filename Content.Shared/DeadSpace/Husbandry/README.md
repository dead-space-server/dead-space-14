# Husbandry: единая система животных

Скот (корова, коза, овца, свинья, куры, утки) живёт по одним правилам. Модуль перенесён из Project Horizon (автор mrl4an) и доработан под этот репозиторий.

## Что есть

| Часть | Где | Что делает |
|---|---|---|
| Нужды | `Needs/`, `AnimalNeedsSystem` | сытость и жажда убывают, при нуле урон. Платить ими за молоко, шерсть и яйца можно через `SharedAnimalNeedsSystem.TryConsumeSatiety` |
| Питание | `Feeding/`, `AnimalFeedingSystem` | рацион (`Diet`), поилка (`WaterSource`), кормушка (`AnimalFeeder`), кормление из рук |
| Свой ИИ и ходьба | `Npc/*`, `Walking/`, `Wander/` | HTN `LivestockCompound`: найти еду или воду, дойти, поесть. Ходьба идёт мимо `NPCSteeringSystem` |
| Пол и рост | `Sex/`, `Growth/` | стадии `baby` → `adult`: размер, мясо, расход сытости |
| Размножение | `Breeding/` | самка + самец своего вида (`species`), оба взрослые, сытые и напоенные; беременность, роды, лимиты |
| Загон | `Pen/` | помещение, ограниченное стенами (или квадрат 15×15 вокруг «дома»); по нему ищется пара для размножения |

Пчёлы (`Content.*/DeadSpace/Beekeeping`) работают отдельно: см. `BeeAISystem`.

## Нагрузка (сервер 100+ игроков)

- Нужды: арифметика раз в `updateRate` (1 с) на животное, первый тик размазан случайно.
- Поиск еды и воды: только когда животное голодно, радиус 25, после неудачи пауза `husbandry.search_cooldown` (20 с).
- Размножение: самка ищет пару раз в 1–2 минуты и только если сама готова. Предел животных рядом (`capacity`) и на весь сервер (`husbandry.breeding.population_cap`).
- Загон: замкнутое помещение считается один раз на всех животных в нём, кэш 30 с.
- Пчёлы: думают дважды в секунду, цветы ищутся запросом по радиусу 5 от улья.

## CVar

| CVar | По умолчанию | Смысл |
|---|---|---|
| `husbandry.breeding.enabled` | true | размножение вообще |
| `husbandry.breeding.population_cap` | 150 | предел животных с `AnimalBreeding` на сервере |
| `husbandry.search_cooldown` | 20 | пауза после неудачного поиска, с |

## Как добавить животное

Родитель `BaseHusbandryAnimal` (`Resources/Prototypes/_DeadSpace/Husbandry/base.yml`), затем `AnimalNeeds`, `Diet`, `Growth` со стадиями `baby` и `adult`, `AnimalBreeding` (`species`, `offspring`). Образец: `MobCow` в `animals.yml`. Молоко, шерсть и яйца работают как раньше (`Udder`, `Wooly`, `EggLayer`), но платят `AnimalNeeds`, если он есть (правки помечены `DS14`).
