# Husbandry: единая система животных

Скот (корова, коза, овца, свинья, куры, утки) живёт по одним правилам. Модуль перенесён из Project Horizon (автор mrl4an) и доработан под этот репозиторий. Животные без компонентов модуля (кошки, собаки, гатланч и т. д.) остаются на старой системе.

## Что есть

| Часть | Где | Что делает |
|---|---|---|
| Нужды | `Needs/`, `SharedAnimalNeedsSystem` | сытость и жажда убывают, при нуле урон. Растут через желудок: обработчик `Satiate` (`AnimalSatiateEffectSystem`) превращает метаболизм реагентов в очки |
| Питание | `Feeding/`, `AnimalFeedingSystem` | еда кусками (штатный `IngestionSystem`), питьё из открытой ёмкости; рацион и список напитков в `Diet`, кормушка `AnimalFeeder`, поилка `WaterSource` |
| Загон | `Pen/`, `AnimalPenSystem` | дом животного (где оно впервые было) и загон вокруг него: помещение со стенами или квадрат 15×15; животное не выбирает цель вне загона; маршрут внутри загона ищется обходом в ширину (без A*) |
| ИИ и ходьба | `Npc/*`, `Walking/`, `Wander/` | HTN `LivestockCompound`: найти еду или воду в загоне, дойти, поесть, прогулки (в т. ч. вокруг игрока, за самкой, за стадом). Ходьба идёт мимо `NPCSteeringSystem` |
| Пол и рост | `Sex/`, `Growth/` | стадии `baby` → `adult`; имена по полу (бык, корова, петух…); молоко даёт только самка, яйца несёт только самка |
| Размножение | `Breeding/` | самка + самец своего вида в одном загоне, оба взрослые и сытые; беременность, роды, лимиты |
| Ферма без игрока | `Farm/AnimalFarmSystem` | кормит и поит спящих животных из загона без ходьбы (то, что съедают и выпивают наблюдаемые, но без ходьбы), бюджет за цикл |

Пчёлы (`Content.*/DeadSpace/Beekeeping`): без игрока в `ActiveRange` (40) мозг пчелы выключен, улей сам добавляет пыльцу (под тем же выключателем фермы).

## Как животное остаётся в загоне

- Дом задаётся при первой проверке загона; загон считается **от дома**, а не от места, где животное стоит. Утащили животное: оно всё равно принадлежит старому загону, новый дом получается только после `RehomeTime` (60 с) стояния вне загона.
- `AnimalPenSystem` отвечает на `AnimalTargetCheckEvent`: место, еда или вода вне загона не выбираются.
- У животных нет `DoorBumpOpener`: двери они сами не открывают.

## Нагрузка (сервер 100+ игроков)

- Нужды: арифметика раз в `updateRate`, первый тик размазан случайно.
- Поиск еды и воды: только когда животное голодно, внутри загона (область уже посчитана и закэширована), один обход в ширину находит ближайшее из всех целей. Пауза `husbandry.search_cooldown` после неудачи или еды.
- Размножение: самка ищет пару раз в 1–2 минуты, сначала бросок шанса, потом загон.
- Загон: замкнутое помещение считается один раз на всех животных в нём, кэш `husbandry.pen.cache_time`.
- Ферма: раз в `husbandry.farm.interval`, не больше `husbandry.farm.budget` животных за цикл, по кругу, только голодные и жаждущие, только те, у кого ИИ спит.
- Пчёлы: думают дважды в секунду; без игрока рядом не делают ничего.

## CVar

| CVar | По умолчанию | Смысл |
|---|---|---|
| `husbandry.farm.enabled` | true | ферма без игрока и офлайн-мёд (выключатель при проблемах) |
| `husbandry.farm.interval` | 15 | период фермы, с |
| `husbandry.farm.budget` | 16 | животных за цикл фермы |
| `husbandry.breeding.enabled` | true | размножение вообще |
| `husbandry.breeding.population_cap` | 150 | предел животных с `AnimalBreeding` на сервере |
| `husbandry.search_cooldown` | 20 | пауза после неудачного поиска или еды, с |
| `husbandry.pen.cache_time` | 30 | как долго хранится посчитанный загон, с |
| `husbandry.wander.player_scan_interval` | 2 | как часто берутся позиции игроков (прогулки вокруг игрока, пчёлы) |

## Что пьют животные

Контейнер считается питьём, только если **всё** в нём входит в `Diet.drinkReagents` (по умолчанию `Water`). Кислоту, кровь, лекарства и смеси с ними животные не пьют.

## Дебаг-анализатор

Показывает здоровье, нужды, рост, размножение, загон, состояние пчелы, улья и опыления. Работает только у админов (`DebugAnalyzer.adminOnly`).

## Как добавить животное

Родитель `BaseHusbandryAnimal` (`Resources/Prototypes/_DeadSpace/Husbandry/base.yml`), затем `AnimalNeeds`, `Diet`, `Growth` со стадиями `baby` и `adult` (имена по полу в `names`), `AnimalBreeding` (`species`, `offspring`). Образец: `MobCow` в `animals.yml`. Молоко, шерсть и яйца работают как раньше (`Udder`, `Wooly`, `EggLayer`), но платят `AnimalNeeds`, если он есть (правки помечены `DS14`).
